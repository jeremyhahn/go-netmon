Configuration export and import

Moves this instance's configuration between deployments. It does not carry metric history — see below.

What it holds
Devices and their SNMP settings, profiles, MIB assignments and per-assignment OID filters, poll intervals, and the MIB source files the configuration refers to — so it restores onto a fresh instance without importing MIBs by hand first.
What it does not hold
Metric history, Grafana dashboards, and anything else living in Prometheus. An import replaces configuration only.
Use it to
Move a configuration to another host, keep a reviewable copy before a change, or seed a new deployment.

An export is a credential. It contains SNMP community strings in clear text. Store it as you would store a password.

Full backup and restore

Everything the stack holds, including metric history. Run from a terminal on the host — not from this page.

What it holds
Every Docker volume: the web UI store, the poller's MIB store and imported MIB sources, the whole Prometheus metric history, and Grafana's database and dashboards. Plus config.yaml and prometheus.yml.
Consistency
Backups are cold. Every service is stopped, the data is copied at rest, and exactly the services that were running are started again — about 12 seconds of downtime for this deployment. The stores are PebbleDB and Prometheus TSDB; neither can be copied safely while running.
Why not a button here
A backup stops every container in the project, including the web UI serving this page. It cannot stop itself mid-request and then tell you how it went.

Commands

# Back up everything. Stops the stack, copies, restarts it.
make backup

# Check an archive end to end. Reads only, changes nothing.
make backup-verify FROM=backups/netmon-20260811T173450Z

# Print the restore plan and change nothing.
make restore FROM=backups/netmon-20260811T173450Z

# Apply it.
make restore FROM=backups/netmon-20260811T173450Z YES=1

The same tool is the binary bin/netmon-backup, which needs only Docker — copy it alongside your backups and a restore needs no toolchain and no checkout. Full detail in docs/operations/backup-restore.md.
